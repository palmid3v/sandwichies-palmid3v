## Cómo interpretar las referencias

La versión v2 es la referencia vigente. La primera presentación queda como antecedente y no debe prevalecer si hay diferencias.

Los diseños de Canva son editables y contienen las composiciones completas. Los thumbnails de Canva son vistas previas temporales; no se copian como archivos permanentes porque el conector disponible no proporciona una exportación binaria estable en esta sesión. Para incorporar PNG/PDF autocontenidos al repositorio, exportar la presentación desde Canva y agregar los archivos exportados a esta carpeta, conservando estos enlaces como fuente editable.

## Uso obligatorio

- Revisar primero v2.
- Priorizar cliente mobile y admin mobile.
- Usar desktop para administración integral.
- No crear pantallas que permitan al cliente elegir mesa.
- No convertir el grupo en un pedido compartido.
- Respetar capacidad máxima 9, radio 50 m, zona geográfica y estados individuales.
