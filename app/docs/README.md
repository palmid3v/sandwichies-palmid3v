# Documentación de Sandwiches

Esta carpeta organiza el material operativo y técnico del proyecto productivo. La carpeta `v0.1/` conserva la línea base histórica; no es la fuente de verdad de la implementación actual.

- `product/`: propósito, reglas y flujos reales.
- `architecture/`: modelo compartido, seguridad y flujo de órdenes.
- `development/`: estructura, entorno y pruebas.
- `deployment/`: controles de release; no contiene secretos.
- `tasks/`: solicitudes y reportes trazables.
- `audits/`: auditorías históricas.

La fuente de los valores monetarios actuales es `shared/catalog.js` y `shared/business.js`.
