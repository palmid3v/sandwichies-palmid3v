# 🥪 Sandwichies

**Sandwichies** es una aplicación web para crear sandwiches personalizados y gestionar pedidos de una forma sencilla y visual.

## 🌮 ¿Qué es?

La app nace como un **sandwich builder** y evoluciona hacia una solución digital para un pequeño negocio de comida.

El cliente puede armar su sandwich a su gusto y enviar el pedido, mientras que el negocio dispone de un espacio administrativo para consultar y gestionar las órdenes.

## 🧑‍🍳 ¿Qué puede hacer el cliente?

- 🥖 Elegir el tamaño del sandwich.
- 🥩 Seleccionar proteínas y cantidades.
- 🥬 Personalizar ingredientes y toppings.
- 🧀 Agregar extras.
- 🛒 Crear un pedido con varios sandwiches.
- 🚚 Elegir domicilio o recoger.
- 💳 Seleccionar el método de pago.
- 📝 Añadir notas al pedido.
- 📱 Recibir el resumen del pedido para continuar por WhatsApp.

## 🧾 ¿Qué puede hacer el negocio?

- 📦 Consultar pedidos.
- 🔄 Actualizar el estado de las órdenes.
- 💰 Consultar información de ventas.
- 📊 Visualizar un dashboard administrativo.
- 📦 Consultar una estimación del inventario utilizado.

## 🎨 Diseño

Sandwichies utiliza una identidad visual **tropical, fresca y gastronómica**, con colores inspirados en ingredientes y alimentos.

La interfaz está pensada para funcionar tanto en **desktop como en dispositivos móviles**, con animaciones y transiciones suaves. ✨

## 🛠️ Tecnología

El proyecto está construido principalmente con:

- ⚛️ React
- ⚡ Vite
- 🔥 Firebase
- 🎨 CSS
- ☁️ Firebase Cloud Functions
- 🗄️ Firestore
