# 🥪 Sandwichies — Configurador y operaciones

> **by PALMI-D3V** · Producto digital en desarrollo continuo.

Experiencia digital para configurar sándwiches y preparar una plataforma de operaciones del negocio, con catálogo, precios confiables, pedidos, inventario y herramientas administrativas.

## ✨ Funcionalidades

- Configuración de productos de 15 cm y 30 cm
- Selección de proteínas, toppings y extras
- Carrito y flujo de solicitud de pedido
- Resumen de pedido para WhatsApp
- Panel administrativo y seguimiento de pedidos
- Visibilidad de pagos y señales de inventario
- Reglas de negocio compartidas para catálogo, recetas y precios

## 🛠️ Tecnología

React · JavaScript · Firebase/Firestore · Vite
